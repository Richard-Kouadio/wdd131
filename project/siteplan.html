Healthy Living Hub

Website Planning Document

Site Name

Healthy Living Hub

The name "Healthy Living Hub" was selected because it clearly communicates that the website provides trustworthy information about healthy eating, exercise, and wellness.

Site Purpose

Healthy Living Hub is designed to help visitors improve their lifestyle by offering healthy recipes, exercise tips, nutrition information, and wellness advice.

Scenarios

  • What are some easy and healthy meals I can prepare at home?
  • How can I start exercising if I have never worked out before?

Color Schema

  • Sea Green (#2E8B57) – Used for headings, header, footer, and buttons.
  • Light Gray (#F5F5F5) – Used as the page background.
  • Dark Gray (#333333) – Used for body text.

Typography

  • Merriweather – Used for headings.
  • Roboto – Used for body text.
